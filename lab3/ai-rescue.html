AI Rescue Recipes

Our planned AI feature turns the food closest to its date into a simple meal. It is a plan and is not built yet.

How it would work

  • Input: items expiring within two days, with portions, plus an optional diet choice.
  • Output: up to three cheap recipes, starting with the most urgent item.
  • Where: a Rescue button on the shared fridge list.
  • Approach: connect an existing language model through an API.

A small server would call the model, so the secret API key never reaches the browser.

Example result (written by hand)

Input: kefir (today), rice (1 day), carrots (2 days).

Suggestion: Carrot rice with a kefir sauce. Fry the grated carrots, add the rice, then serve with kefir, salt and garlic.

Still needed: oil, garlic.

Honest limits

  • The model can invent steps, so recipes need a human eye.
  • It cannot tell if food is safe. Students still check it.
  • It does not know allergies unless a user tells it.
  • Each request costs money and needs internet access.
